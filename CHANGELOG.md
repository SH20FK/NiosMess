# Список изменений NiosMess

## [3.58.3]
• В окне обновления показывается только последний актуальный чейнджлог
• Правило согласования описания изменений напрямую с пользователем

## [3.58.2]
• Простой и понятный список изменений в окне обновления
• Автоматическая загрузка чейнджлога без ограничений API
• Мелкие улучшения стабильности

## [3.58.1]
• Окно обновления теперь выезжает снизу плавной шторкой
• Автоматическая проверка обновлений раз в сутки при старте
• Скачивание APK в фоновом режиме с индикатором в шторке Android
• Мелкие исправления интерфейса и анимаций

## [3.58.0]
• Встроенное бесшовное обновление приложения (OTA)
• Проверка разрешений на установку APK
• Уведомления о скачанном обновлении

## [3.57.0]
• Улучшения личных чатов и ответов на стикеры
• Исправления ленты NiosGram и комментариев
