## Вердикты

| вердикт | когда |
|---|---|
| **нужен** | реально используется в коде |
| **дубль** | функционально перекрывается другим пакетом (укажи каким) |
| **мёртвый** | объявлен в pubspec, но ни одного импорта/нативного использования |
| **только транзитивно** | объявлен, но код пользуется API другого пакета |
| **внимание: <причина>** | устаревший API, обход через `ignore:`, дублирующая реализация в проекте |

Отдельно помечай: пакет объявлен дважды по смыслу (два аудио-движка, два загрузчика
картинок, два HTTP-клиента), и пакет, чью функциональность проект написал сам.
