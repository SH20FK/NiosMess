## 1. Что сейчас в коде

В `_MainShellScreenState`:

```dart
_tabAnimController = AnimationController(vsync: this, duration: const Duration(milliseconds: 180))..value = 1.0;
_tabFadeAnimation = CurvedAnimation(parent: _tabAnimController, curve: Curves.easeOutCubic);
// ...
final Widget body = FadeTransition(
  opacity: _tabFadeAnimation,
  child: IndexedStack(index: currentIndex, children: /* 4 страницы */),
);
```

Пять причин, почему это читается как «дёшево»:

1. **Кросс-фейда нет.** `IndexedStack` меняет `index` в том же кадре, значит старая страница исчезает мгновенно, а затем новая проявляется из пустоты. Это не переход, это жёсткая склейка плюс засветка.
2. **Нет направления.** «Чаты → Профиль» и «Профиль → Чаты» выглядят идентично, хотя пространственно это движения в противоположные стороны. Мозг не получает подтверждения, куда он переместился, и вся навигация ощущается как перерисовка, а не как перемещение.
3. **Самая дорогая анимация из возможных.** `FadeTransition` поверх всего `IndexedStack` — это `saveLayer` на полноэкранное поддерево каждый кадр в течение 180 мс. Платим полной композицией экрана за эффект, который почти не виден.
4. **MD2-тайминг.** 180 мс и `Curves.easeOutCubic` при том, что `M3Durations` и `M3SpringCurves` уже лежат в проекте, а протокол в `AGENTS.md` требует их «без исключений».
5. **Нижняя панель не участвует.** Стандартный `NavigationBar` гасит индикатор в одном слоте и зажигает в другом. Пилюля никуда не едет, иконки не реагируют, метки не меняют вес. Панель и контент живут в разных вселенных.

<aside>
🔎

Попутная находка: `IndexedStack` пропускает только **paint**, а **layout всех активированных детей выполняет каждый кадр**. Прямо сейчас четыре тяжёлых экрана проходят layout на каждом кадре шелла. Это отдельный пункт ниже.

## 2. Концепт: три варианта

| Вариант | Как ощущается | Цена | Вердикт |
| --- | --- | --- | --- |
| **A. Shared Axis X + глубина по текстуре** | Уходящий экран отъезжает в сторону и отступает в глубину, входящий влетает с противоположной стороны и садится с пружинным доводом | Один блит текстуры + один transform живого дерева. Ноль `saveLayer` | **Рекомендую** |
| B. Vertical container transform | Табы «поднимаются» снизу, как лист | Дешево, но конфликтует с анимацией клавиатуры и с bottom sheets, а вертикаль в приложении уже занята | Нет |
| C. Свайпаемый `PageView` между табами | Максимально «мессенджерно», как Telegram | Отдельный большой проект: конфликт с горизонтальными свайпами чат-листа, `Dismissible`, свайпом-на-ответ | Потом, отдельной задачей |

### Вариант A по кадрам

1. В момент тапа, **до** `context.go`, текущая страница растеризуется в `ui.Image` через `RepaintBoundary.toImageSync`. Слой ещё свежий, поэтому в текстуру попадает ровно то, что человек видит.
2. Роут меняется, `IndexedStack` переключает индекс, новая страница строится как обычно.
3. Один контроллер на `M3Durations.medium2` (300 мс) гонит два слоя:
    - **входящий живой экран** (низ стека): сдвиг `direction * 0.14` ширины → 0, масштаб 0.96 → 1.0, кривая `M3SpringCurves.spatial`. **Без `Opacity`.**
    - **уходящая текстура** (верх стека): сдвиг 0 → `-direction * 0.14`, масштаб 1.0 → 0.94, альфа 1 → 0 через `RawImage.opacity`, кривая `M3SpringCurves.expressiveDecel`.
4. По завершении текстура освобождается через `image.dispose()`, дерево возвращается к исходному виду.

Почему это одновременно выразительно и дешево:

- `direction` = знак разницы индексов, поэтому переход **направленный**: вправо по табам — вход справа, влево — слева.
- Текстура на верхнем слое в момент t=0 полностью покрывает экран, поэтому **вспышки фона не будет** ни на один кадр, в отличие от наивного slide-in.
- Альфа применяется на листовом `RenderImage` через `Paint.color`, а не через слой. **`saveLayer` не создаётся вообще ни для одного слоя.** Живой экран получает только transform, то есть чистую матрицу композиции.
- Пружина `spatial` нормализована (`raw / rawEnd` в `SpringCurve`), но в середине пути даёт перелёт больше 1.0 — именно он и читается как «дорогая» анимация. Перелёт применён только к transform, к альфе идёт монотонный `expressiveDecel`, как требует пункт 5 моторного протокола.

## 3. Код: новый виджет

Новый файл `pulse_flutter/lib/widgets/nav/tab_shared_axis_switcher.dart`:

```dart
import 'dart:ui' as ui;

import 'package:flutter/material.dart';
import 'package:flutter/rendering.dart';
import 'package:pulse_flutter/core/motion/m3_spring_constants.dart';

/// Imperative hook: the shell rasterizes the outgoing tab at the exact moment
/// of the tap, while its layer is still freshly painted.
class TabTransitionController {
  _TabSharedAxisSwitcherState? _state;

  /// Call immediately BEFORE context.go('/main/<tab>').
  void captureOutgoing() => _state?._captureOutgoing();
}

/// Direction-aware M3 Expressive shared-axis transition between shell tabs.
///
/// The outgoing tab is captured once as a GPU texture and animated as a
/// [RawImage], so it costs a single texture blit instead of a build, layout
/// and paint pass. The incoming tab is animated with transforms only, so the
/// whole transition allocates zero save layers.
class TabSharedAxisSwitcher extends StatefulWidget {
  const TabSharedAxisSwitcher({
    required this.index,
    required this.children,
    required this.controller,
    this.animate = true,
    this.shift = 0.14,
    this.duration = M3Durations.medium2,
    super.key,
  });

  final int index;
  final List<Widget> children;
  final TabTransitionController controller;

  /// False on tier C, on reduced-motion, or on weak-device mode: instant swap.
  final bool animate;

  /// Horizontal travel as a fraction of page width.
  final double shift;

  final Duration duration;

  @override
  State<TabSharedAxisSwitcher> createState() => _TabSharedAxisSwitcherState();
}

class _TabSharedAxisSwitcherState extends State<TabSharedAxisSwitcher>
    with SingleTickerProviderStateMixin {
  static const double _outScale = 0.94;
  static const double _inScale = 0.96;

  /// Load-bearing twice: it lets us find the boundary to rasterize, and it
  /// keeps the live subtree alive when the tree shape changes between the
  /// steady state and the animating Stack.
  final GlobalKey _boundaryKey = GlobalKey();

  late final AnimationController _controller;
  late final Animation<double> _spatial;
  late final Animation<double> _outAlpha;

  ui.Image? _snapshot;
  double _snapshotScale = 1.0;
  int _direction = 1;

  @override
  void initState() {
    super.initState();
    widget.controller._state = this;
    _controller = AnimationController(vsync: this, duration: widget.duration)
      ..value = 1.0
      ..addStatusListener(_onStatus);
    _spatial = CurvedAnimation(
      parent: _controller,
      curve: M3SpringCurves.spatial,
    );
    // Leaf-level alpha on the texture only: no Opacity widget, no save layer.
    // Monotonic curve, never an overshoot curve (motion protocol rule 5).
    _outAlpha = Tween<double>(begin: 1.0, end: 0.0).animate(
      CurvedAnimation(
        parent: _controller,
        curve: M3SpringCurves.expressiveDecel,
      ),
    );
  }

  @override
  void didUpdateWidget(covariant TabSharedAxisSwitcher oldWidget) {
    super.didUpdateWidget(oldWidget);
    if (!identical(oldWidget.controller, widget.controller)) {
      oldWidget.controller._state = null;
      widget.controller._state = this;
    }
    if (oldWidget.index == widget.index) return;

    _direction = widget.index > oldWidget.index ? 1 : -1;

    if (!widget.animate) {
      _controller.value = 1.0;
      _disposeSnapshot();
      return;
    }

    // Fallback capture for programmatic switches (deep link, back button).
    if (_snapshot == null) _captureOutgoing();
    _controller.forward(from: 0.0);
  }

  void _onStatus(AnimationStatus status) {
    if (status != AnimationStatus.completed &&
        status != AnimationStatus.dismissed) {
      return;
    }
    if (_snapshot != null) {
      setState(_disposeSnapshot);
    }
  }

  void _disposeSnapshot() {
    _snapshot?.dispose();
    _snapshot = null;
  }

  void _captureOutgoing() {
    if (!widget.animate || !mounted) return;
    final RenderObject? object = _boundaryKey.currentContext?.findRenderObject();
    // debugNeedsPaint is a real getter in release builds: if the boundary is
    // dirty, its layer is stale and the texture would be blank.
    if (object is! RenderRepaintBoundary || object.debugNeedsPaint) return;
    _disposeSnapshot();
    try {
      // Cap at 2.0: a 3x full-screen texture costs bandwidth for nothing.
      final double scale =
          MediaQuery.devicePixelRatioOf(context).clamp(1.0, 2.0);
      _snapshot = object.toImageSync(pixelRatio: scale);
      _snapshotScale = scale;
    } catch (_) {
      _disposeSnapshot();
    }
  }

  @override
  void dispose() {
    widget.controller._state = null;
    _controller.dispose();
    _disposeSnapshot();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final Widget live = RepaintBoundary(
      key: _boundaryKey,
      child: IndexedStack(index: widget.index, children: widget.children),
    );

    // Steady state: exactly the tree we have today, zero animation overhead.
    if (_snapshot == null && _controller.value == 1.0) return live;

    return Stack(
      fit: StackFit.expand,
      children: <Widget>[
        AnimatedBuilder(
          animation: _spatial,
          child: live,
          builder: (BuildContext context, Widget? child) {
            final double t = _spatial.value;
            return FractionalTranslation(
              translation: Offset(_direction * widget.shift * (1.0 - t), 0.0),
              child: Transform.scale(
                scale: ui.lerpDouble(_inScale, 1.0, t)!,
                child: child,
              ),
            );
          },
        ),
        if (_snapshot != null)
          IgnorePointer(
            child: AnimatedBuilder(
              animation: _spatial,
              builder: (BuildContext context, Widget? child) {
                final double t = _spatial.value;
                return FractionalTranslation(
                  translation: Offset(-_direction * widget.shift * t, 0.0),
                  child: Transform.scale(
                    scale: ui.lerpDouble(1.0, _outScale, t)!,
                    child: RawImage(
                      image: _snapshot,
                      scale: _snapshotScale,
                      opacity: _outAlpha,
                      fit: BoxFit.cover,
                      filterQuality: FilterQuality.low,
                    ),
                  ),
                );
              },
            ),
          ),
      ],
    );
  }
}
```

<aside>
⚠️

`_boundaryKey` обязателен именно как `GlobalKey`. Между спокойным состоянием (`live` напрямую) и анимацией (`live` внутри `Stack` и `AnimatedBuilder`) меняется глубина дерева. Без глобального ключа Flutter деактивирует поддерево и **потеряет всё состояние**: позиции скролла, контроллеры, открытые сессии. С ключом элемент переносится и состояние живёт.

</aside>

## 5. Код: живой индикатор в нижней панели

Без этого переход всё равно будет ощущаться наполовину: контент едет, а панель мигает. Дефолтный `NavigationBar` **не перемещает** пилюлю между слотами, он гасит её в одном и зажигает в другом. Едущая пилюля со squash-and-stretch — самый заметный апгрейд восприятия качества на весь экран.

```dart
import 'dart:math' as math;
import 'dart:ui' as ui;

import 'package:flutter/material.dart';
import 'package:pulse_flutter/core/motion/m3_spring_constants.dart';

class TravelingNavIndicator extends StatefulWidget {
  const TravelingNavIndicator({
    required this.index,
    required this.count,
    required this.color,
    required this.animate,
    this.pillHeight = 34.0,
    this.maxPillWidth = 72.0,
    super.key,
  });

  final int index;
  final int count;
  final Color color;
  final bool animate;
  final double pillHeight;
  final double maxPillWidth;

  @override
  State<TravelingNavIndicator> createState() => _TravelingNavIndicatorState();
}

class _TravelingNavIndicatorState extends State<TravelingNavIndicator>
    with SingleTickerProviderStateMixin {
  late final AnimationController _controller;
  late final Animation<double> _spatial;
  int _from = 0;

  @override
  void initState() {
    super.initState();
    _from = widget.index;
    _controller = AnimationController(
      vsync: this,
      duration: M3Durations.medium2,
    )..value = 1.0;
    _spatial = CurvedAnimation(
      parent: _controller,
      curve: M3SpringCurves.spatial,
    );
  }

  @override
  void didUpdateWidget(covariant TravelingNavIndicator oldWidget) {
    super.didUpdateWidget(oldWidget);
    if (oldWidget.index == widget.index) return;
    _from = oldWidget.index;
    if (widget.animate) {
      _controller.forward(from: 0.0);
    } else {
      _controller.value = 1.0;
    }
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  double _slotX(int i) =>
      widget.count <= 1 ? 0.0 : (2 * i + 1) / widget.count - 1.0;

  @override
  Widget build(BuildContext context) {
    return LayoutBuilder(
      builder: (BuildContext context, BoxConstraints constraints) {
        final double slot = constraints.maxWidth / widget.count;
        final double baseWidth =
            (slot * 0.62).clamp(48.0, widget.maxPillWidth);
        final double travel =
            ((widget.index - _from).abs() / widget.count).clamp(0.0, 1.0);

        return AnimatedBuilder(
          animation: _spatial,
          builder: (BuildContext context, Widget? child) {
            final double t = _spatial.value;
            // Squash and stretch: the pill elongates mid-flight, then settles.
            final double wobble =
                math.sin(math.pi * t.clamp(0.0, 1.0)) * travel;
            return Align(
              alignment: Alignment(
                ui.lerpDouble(_slotX(_from), _slotX(widget.index), t)!
                    .clamp(-1.0, 1.0),
                0.0,
              ),
              child: SizedBox(
                width: baseWidth * (1.0 + 0.34 * wobble),
                height: widget.pillHeight * (1.0 - 0.16 * wobble),
                child: DecoratedBox(
                  decoration: ShapeDecoration(
                    color: widget.color,
                    shape: const StadiumBorder(),
                  ),
                ),
              ),
            );
          },
        );
      },
    );
  }
}
```

Геометрия и сборка в `app_bottom_nav.dart`:

- Индикатор кладётся **под** ряд слотов: `Stack` → `Positioned` с высотой ряда иконок, поверх — прозрачный ряд из четырёх `Expanded`.
- Дефолтный `NavigationBar` приходится заменить на свой ряд, потому что его внутренняя раскладка не даёт попасть в центр слота. Это примерно 120 строк: `Row` из четырёх `Expanded`, в каждом `InkResponse` и колонка «иконка + метка», высота 64, центр иконки на 24 от верха. Всё остальное — бейджи, `context.l10n`, `HapticService.tap()`, `playUiTick()`, варианты floating и docked — переносится из текущего файла один в один.
- Цвет пилюли остаётся `scheme.secondaryContainer`.

Моторика иконки и метки в слоте:

```dart

  curve: M3SpringCurves.bouncy, // overshoot allowed on transform, never on alpha
```

## 6. Тиры и доступность

| Условие | Поведение |
| --- | --- |
| Tier A | Сдвиг 0.14, 300 мс, stretch 0.34, bounce иконки |
| Tier B | Сдвиг 0.10, 250 мс, stretch 0.18 |
| Tier C, `optimizeForWeakDevices`, `MediaQuery.disableAnimationsOf` | `animate: false`: мгновенная подмена, снимок не создаётся, контроллеры не запускаются, индикатор прыгает |

`optimizeForWeakDevices` уже опускает тир до `powerSaver` внутри `AdaptivePerformanceNotifier`, так что отдельная проверка не нужна — достаточно `tier.isTierC`.

## 7. Попутный выигрыш: layout неактивных табов

`IndexedStack` лэйаутит всех активированных детей каждый кадр. Четыре экрана вместо одного. Это стоит проверить замером и, если подтвердится, заменить `IndexedStack` на `Stack`, где невидимые табы завёрнуты в `Offstage`.

Осторожно: `Offstage` пропускает и layout, поэтому при возврате на таб будет один кадр повторной раскладки. На чат-листе это может дать заметный рывок ровно в тот момент, когда начинается анимация. Поэтому это **отдельная задача после** основной, с замером до и после, а не часть этой.

## 8. Чего делать нельзя (гейты)

```bash
# в новом коде не должно быть ни одного попадания
rg -n "FadeTransition|Opacity\(" lib/widgets/nav/ lib/screens/main_shell_screen.dart
rg -n "Curves\." lib/widgets/nav/ lib/screens/main_shell_screen.dart

# MediaQuery внутри builder у AnimatedBuilder: запрещено
rg -n -A3 "builder: \(BuildContext context, Widget\? child\)" lib/widgets/nav/ | rg "MediaQuery"

# каждый toImageSync обязан иметь dispose в том же файле
rg -l "toImageSync" lib | xargs -I{} sh -c 'rg -c "\.dispose\(\)" {} >/dev/null || echo "LEAK: {}"'
```

Отдельно: не анимировать `Opacity` живой страницы ни под каким предлогом. Ровно это и делает текущий переход дорогим и незаметным одновременно.

## 9. Критерии приёмки

1. Переход направленный: «Чаты → Профиль» входит справа, «Профиль → Чаты» — слева. Проверяется глазами и виджет-тестом на знак сдвига.
2. Ни одного кадра с пустым фоном между экранами.
3. **Ноль `saveLayer`** за весь переход. Проверка: DevTools timeline, слой Layers, либо `debugRepaintRainbow`.
4. Состояние табов живёт: позиция скролла чат-листа сохраняется после 20 переключений туда-обратно.
5. Текстура освобождается: `expect(image.debugDisposed, isTrue)` после `pumpAndSettle`.
6. `animate: false` не создаёт ни `RawImage`, ни запущенных контроллеров.
7. Работает и в desktop-ветке, где переключение идёт через `NavigationRail.onDestinationSelected`.
8. Индикатор приезжает синхронно с контентом: одинаковые `M3Durations` и кривая, запуск в одном кадре.
9. `flutter analyze` — ноль новых замечаний.

**Два риска, которые надо снять первыми.**

1. `toImageSync` на полноэкранной границе — это выделение GPU-текстуры на каждый тап по табу. При частом дёрганье табов туда-сюда можно накопить несколько живых изображений, если `dispose` где-то не сработает. Отсюда жёсткое правило: единственное поле `_snapshot`, освобождение в трёх точках (статус-листенер, повторный capture, `dispose`) и тест на `debugDisposed`.
2. Снимок делается из `_onTapTab`, но табы меняются и другими путями: системная кнопка «назад» уводит на `/main/chats`, диплинк может открыть любой таб. Для них работает fallback-capture внутри `didUpdateWidget`, и он менее надёжен: граница уже может быть грязной. В этом случае переход деградирует до чистого slide-in без текстуры — это допустимо, но проверить глазами нужно именно оба пути.
