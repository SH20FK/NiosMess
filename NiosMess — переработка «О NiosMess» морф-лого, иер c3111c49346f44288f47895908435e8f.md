# NiosMess — переработка «О NiosMess»: морф-лого, иерархия действий, минус список версий

Разбор текущего `settings_about_screen.dart` на HEAD `a625e3b0` (SHA файла `23b6838f`, версия `3.61.0+144`). Все находки — из кода и скриншотов, ничего не придумано.

## Корень проблемы

Структура экрана правильная, но каждый визуальный слой решён «в лоб»:

1. **Морфинга нет вообще.** Лого не морфится — оно кросс-фейдится двумя копиями через `AnimatedSwitcher` + `ScaleTransition`. Отсюда «лагано и некрасиво».
2. **Нет иерархии действий.** Семь одинаковых `ActionChip` в центрированном `Wrap` — это буквально и есть «набор крошек».
3. **Список версий строится целиком и жадно**, по два контроллера анимации на каждую версию, внутри неленивого `Column`.
4. **Пять радиусов и пять размеров иконок** на одном экране, плюс тональный фон и рамка одновременно на каждой карточке — ничто не читается как «выше».
5. **Двойная неявная анимация** на переключении табов: `AnimatedSize` и `AnimatedSwitcher` тянут один и тот же контент по разным кривым и длительностям.

## 1. Лого: почему морф лагает

Текущий код в `_InteractiveHeroLogoState`:

```
AnimatedSwitcher(
  duration: const Duration(milliseconds: 300),
  switchInCurve: M3SpringCurves.spatial,
  switchOutCurve: M3SpringCurves.snappy,
  transitionBuilder: (child, animation) => ScaleTransition(scale: animation, child: child),
  child: M3Container(currentShape, key: ValueKey(_shapeIndex), width: 78, height: 78, ...),
)
```

Четыре независимые причины рывка:

- **Это не морф.** Уходящая фигура схлопывается в точку, входящая раскрывается из точки, обе — в одном месте одновременно. Примерно 150 мс ты видишь две фигуры друг в друге. Формы не «текут», они «схлопнулись-раскрылись».
- **Пружина на обратном ходе.** `switchOutCurve: M3SpringCurves.snappy` — физическая пружина (damping 0.85, stiffness 340), которую `AnimatedSwitcher` проигрывает реверсом. Реверс пружины даёт недо/перелёт, масштаб уходит за 1.0 → видимый дёрг в середине.
- **Новое поддерево каждый тап.** Новый `ValueKey` → новый `M3Container` → новый клип по 9-угольному/звёздному пути и новая вставка `SvgPicture` внутрь него. Два одновременных `clipPath` по сложной фигуре = `saveLayer` каждый кадр, умноженный на два. Это прямое нарушение правила 1 вашего же корневого `AGENTS.md` («Zero Per-Frame Blur Rasterization»).
- **Нет защиты от спама.** Быстрые тапы накладывают переходы друг на друга, `_shapeIndex` уезжает вперёд анимации.

### Замена: один painter, один контроллер, ноль saveLayer

Фигуры описываются радиальными профилями (для печенья, гема, цветка, солнца и взрыва это точно), радиусы линейно интерполируются, поворот отдаётся `canvas.rotate`. Тригонометрия считается один раз на старте приложения, за кадр — только 180 умножений и один `drawPath`. SVG-глиф передаётся как `child` и рисуется поверх, без клипа и без повторной растеризации.

**Новый файл `lib/widgets/about/morphing_brand_mark.dart`:**

```
import 'dart:math' as math;
import 'package:flutter/material.dart';
import 'package:flutter_svg/flutter_svg.dart';
import 'package:pulse_flutter/core/localization/l10n.dart';
import 'package:pulse_flutter/core/motion/m3_spring_constants.dart';
import 'package:pulse_flutter/core/utils/haptic_service.dart';

const int _kSamples = 180;

final List<Offset> _kUnit = List<Offset>.generate(
  _kSamples,
  (int i) {
    final double a = (i / _kSamples) * 2 * math.pi;
    return Offset(math.cos(a), math.sin(a));
  },
  growable: false,
);

List<double> _scallop({required int lobes, required double depth}) =>
    List<double>.generate(
      _kSamples,
      (int i) => 1.0 - depth * math.cos(lobes * (i / _kSamples) * 2 * math.pi),
      growable: false,
    );

List<double> _polygon(int sides) {
  final double half = math.pi / sides;
  return List<double>.generate(
    _kSamples,
    (int i) {
      final double a = (i / _kSamples) * 2 * math.pi;
      return math.cos(half) / math.cos((a % (2 * half)) - half);
    },
    growable: false,
  );
}

class BrandShape {
  const BrandShape(this.radii, this.spin);
  final List<double> radii;
  final double spin;
}

final List<BrandShape> kBrandShapes = <BrandShape>[
  BrandShape(_scallop(lobes: 9, depth: 0.075), 0.00),  // cookie
  BrandShape(_polygon(6), 0.26),                       // gem
  BrandShape(_scallop(lobes: 6, depth: 0.170), 0.52),  // flower
  BrandShape(_scallop(lobes: 12, depth: 0.110), 0.78), // sunny
  BrandShape(_scallop(lobes: 16, depth: 0.150), 1.04), // burst
];

class _MorphPainter extends CustomPainter {
  _MorphPainter({
    required this.from,
    required this.to,
    required this.t,
    required this.color,
  });

  final BrandShape from;
  final BrandShape to;
  final double t;
  final Color color;

  @override
  void paint(Canvas canvas, Size size) {
    final double r = size.shortestSide / 2;
    final Path path = Path();
    for (int i = 0; i < _kSamples; i++) {
      final double k =
          (from.radii[i] + (to.radii[i] - from.radii[i]) * t) * r;
      final Offset p = _kUnit[i] * k;
      if (i == 0) {
        path.moveTo(p.dx, p.dy);
      } else {
        path.lineTo(p.dx, p.dy);
      }
    }
    path.close();

    canvas.save();
    canvas.translate(size.width / 2, size.height / 2);
    canvas.rotate(from.spin + (to.spin - from.spin) * t);
    canvas.drawPath(path, Paint()..color = color..isAntiAlias = true);
    canvas.restore();
  }

  @override
  bool shouldRepaint(_MorphPainter old) =>
      old.t != t || old.from != from || old.to != to || old.color != color;
}

class MorphingBrandMark extends StatefulWidget {
  const MorphingBrandMark({
    super.key,
    this.size = 84,
    this.onEasterEgg,
  });

  final double size;
  final VoidCallback? onEasterEgg;

  @override
  State<MorphingBrandMark> createState() => _MorphingBrandMarkState();
}

class _MorphingBrandMarkState extends State<MorphingBrandMark>
    with SingleTickerProviderStateMixin {
  late final AnimationController _ctrl = AnimationController(
    vsync: this,
    duration: M3Durations.long2,
  );
  late final Animation<double> _shape = CurvedAnimation(
    parent: _ctrl,
    curve: M3SpringCurves.bouncy,
  );

  int _prev = 0;
  int _curr = 0;
  int _taps = 0;

  void _next() {
    if (_ctrl.isAnimating) return;
    HapticService.selection();
    setState(() {
      _prev = _curr;
      _curr = (_curr + 1) % kBrandShapes.length;
    });
    _ctrl.forward(from: 0);
    _taps++;
    if (_taps >= 5) {
      _taps = 0;
      widget.onEasterEgg?.call();
    }
  }

  @override
  void dispose() {
    _ctrl.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final ColorScheme scheme = Theme.of(context).colorScheme;

    return Semantics(
      button: true,
      label: context.l10n.appName,
      child: GestureDetector(
        onTap: _next,
        behavior: HitTestBehavior.opaque,
        child: RepaintBoundary(
          child: SizedBox.square(
            dimension: widget.size,
            child: AnimatedBuilder(
              animation: _shape,
              child: Center(
                child: SvgPicture.asset(
                  'assets/svg/niosmess_logo_tintable.svg',
                  width: widget.size * 0.52,
                  height: widget.size * 0.52,
                  colorFilter: ColorFilter.mode(
                    scheme.onPrimary,
                    BlendMode.srcIn,
                  ),
                ),
              ),
              builder: (BuildContext context, Widget? child) => CustomPaint(
                painter: _MorphPainter(
                  from: kBrandShapes[_prev],
                  to: kBrandShapes[_curr],
                  t: _shape.value.clamp(0.0, 1.0),
                  color: scheme.primary,
                ),
                child: child,
              ),
            ),
          ),
        ),
      ),
    );
  }
}
```

Что это даёт: одно поддерево вместо двух, ноль `clipPath`, ноль `saveLayer`, SVG растеризуется один раз (он вынесен в `child` у `AnimatedBuilder`), `isAnimating`-гейт убирает наложение тапов, а `M3SpringCurves.bouncy` на радиусах даёт настоящий «упругий» M3E-морф вместо схлопывания.

Опционально: обернуть в `Hero(tag: 'app_brand_logo')` — в фазе 6 (`c1d274ff`) этот тег уже введён в entry-воронке, и тогда вход на экран будет доводить бренд-марку, а не рисовать её с нуля.

## 2. Главная карточка: из крошек в иерархию

Сейчас в `_buildHeroCard` семь `_M3ActionChip` в `Wrap(alignment: WrapAlignment.center)`. Центрированный `Wrap` с элементами разной ширины физически не может выглядеть намеренным — он всегда даст рваные ряды 1/1/2/2/1, что и на скриншоте.

Проблемы кроме раскладки:

- **Нет веса.** «Сообщить о баге» (реальное целевое действие) выглядит ровно как «[ni-os.ru](http://ni-os.ru)».
- **Тач-таргет.** `ActionChip` с `padding: h4 v2` и `fontSize: 12` даёт высоту около 32 dp. Нужно минимум 48.
- **«Устройство» — дубль.** `/settings/system-device` уже есть в Настройках отдельным разделом. На экране «О приложении» ему делать нечего.
- **Радиус 12** у чипов против 28 у карточки и 20 у OTA-блока.
- **Иконки 15 px**, из них две — SVG (`telegram_logo`, `globe`). На 15 px глобус превращается в кашу (видно на скриншоте). Порог для линейных SVG — 18 px.
- **Рамка + тон одновременно.** Карточка `surfaceContainerLow` + `outlineVariant α0.3`, и такая же рамка у OTA-блока, и у табов, и у карточек команды. В итоге ничто не выделяется. По вашему же протоколу глубина — тоном, не рамкой.

## 3. Список версий: убрать

Факты из кода:

- `pastReleases = releases.sublist(1)` — в таб уходят **все** релизы из `assets/CHANGELOG.md`, без лимита.
- Каждый — `_ParsedReleaseTile`, то есть `StatefulWidget` с `AnimatedCrossFade` **и** `AnimatedRotation`. Это два неявных контроллера анимации на версию. На скриншоте видно 10 штук, в файле их уже сильно больше, и по вашему протоколу версия бампается каждую задачу — список будет расти бесконечно.
- Всё это внутри обычного `Column` (не ленивого), который вложен в `AnimatedSize` + `AnimatedSwitcher`. При переключении на «Команду» уходящий таб ещё смонтирован → все тайлы живы и участвуют в layout.
- `_loadChangelog()` парсит весь файл в `initState` на UI-потоке, кэш лежит в `State` → при каждом открытии экрана парсинг заново.

**Решение.** В табе «Новое» остаётся только текущий релиз. 

## 4. Карточки разработчиков

Класс называется `_GoogleContactsDeveloperTile` — имя честно признаёт, что это вёрстка из чужой системы. Плюс реальные баги:

- **Аватары почти невидимы.** `Image.asset(assetPath, fit: BoxFit.contain)` без тинта на фоне `surfaceContainerHighest α0.7`. PNG-и — светлый лайн-арт на прозрачном, то есть светлое на светлом. На скриншоте кот и город читаются как призраки. Фикс: `ColorFilter.mode(scheme.onSecondaryContainer, BlendMode.srcIn)` + фон `secondaryContainer`; ещё лучше — положить аватар в ту же брендовую фигуру, что и лого (`BrandShape` из §1), фон `primary`, тинт `onPrimary`. Тогда команда визуально связана с бренд-маркой.
- **Роль в чипе с `maxLines: 2`.** Чип превращается в двухстрочный абзац и всё равно обрезается: «Руководитель разработки клиента & …». Чип для роли не подходит по определению — он не должен переноситься. Роль = обычный `bodySmall` цветом `onSurfaceVariant`, две строки разрешены, текст целиком.
- **`&` в русской строке** → «и».
- **Радиус 6** у чипа роли — шестой радиус на экране.
- **Данные захардкожены в дереве.** Имена, хэндлы, пути к ассетам и фолбэк-иконки лежат прямо в `_buildDevelopersTab`. Вынести в `const List<TeamMember>` (`core/constants/team.dart`): имя, хэндл, ключ роли для l10n, ассет, индекс фигуры. Добавить человека должно быть правкой данных, а не вёрстки.
- **Карточка не нажимается**, тапается только иконка Telegram. Сделать `InkWell` на всю карточку → Telegram, long-press → скопировать хэндл через `AppToast.showSuccess`.
- **Брейкпоинт 760** → 840 по канону M3 (в аудите дизайн-системы это уже отмечено как общая проблема).
- Опционально: у команды есть аккаунты внутри NiosMess — вести на внутренний профиль вместо внешнего Telegram, чтобы не выкидывать пользователя из приложения.

## 5. Анимации

| Что сейчас | Проблема | Как надо |
| --- | --- | --- |
| `AnimatedSize(250)` вокруг `AnimatedSwitcher(220)` | Две неявные анимации тянут один контент по разным кривым и длительностям — контент «сдвигается, потом щёлкает» | `PageTransitionSwitcher`  • `SharedAxisTransition(horizontal)` из `animations ^2.2.0` (уже в зависимостях), снаружи один `AnimatedSize(M3Durations.medium2, M3SpringCurves.expressiveDecel)` |
| `SlideTransition(Offset(0.015, 0))` | 1,5 % ширины ≈ 5 px — движение физически незаметно | Убрать, shared-axis даёт корректный сдвиг сам |
| `AnimatedCrossFade` без `sizeCurve` | `sizeCurve` по умолчанию линейный, а прозрачность идёт по пружине → высота растёт линейно и «допрыгивает» в конце | Задать `sizeCurve: M3SpringCurves.expressiveDecel` там, где кросс-фейд остаётся |
| `AnimatedRotation(200)`  • `AnimatedCrossFade(200)` в тайле версии | Два разных виджета от одного `setState`, рассинхрон на глаз | Уходит вместе со списком версий; в новом экране истории — один контроллер на раскрытую строку |
| `SegmentedButton` | Никакой моторики при выборе; `fontSize: 12`  • `ellipsis` дают «Что но…» и «Докум…» — обрезанные лейблы прямо на скриншоте | Убрать иконки из сегментов (M3 это допускает) — тогда «Новое / Документы / Команда» влезают целиком; добавить `AnimatedScale` 0.97 на нажатый сегмент; убрать ручной `fontSize` в пользу `labelLarge` |
| Вход на экран | Ничего не анимируется, всё появляется сразу | Стаггер трёх блоков через `flutter_animate ^4.5.2`: `fadeIn(M3Durations.medium2, curve: expressiveDecel)`  • `slideY(begin: 0.04)`, задержки 0 / 50 / 100 мс, строго one-shot (не перезапускать на rebuild) |
| `Md3SquiggleProgress` | Нет `RepaintBoundary` — во время загрузки OTA перерисовывается вся карточка вместе с текстом | Обернуть в `RepaintBoundary` |

## 6. Попутные баги

- `_showBugReportDialog`: два `TextEditingController` **никогда не диспозятся** — утечка на каждое открытие диалога.
- Там же: кнопка отправки подписана `commonSave` («Сохранить») вместо «Отправить».
- Там же: при пустых полях `onPressed` молча делает `return` — кнопка активна и не реагирует. Нужен либо `null` в `onPressed`, либо ошибка в поле.
- Там же: `RoundedRectangleBorder(24)` перебивает `dialogTheme`, который считает радиус из пользовательской настройки `uiCornerRadius`. И `OutlineInputBorder(12)` перебивает `inputDecorationTheme` (filled, без рамки) — поля выглядят как из другого приложения.
- Версионный бейдж: `Semantics(label: aboutVersionCopied(ver))` — скринридер зачитывает «версия скопирована» **до** нажатия. Лейбл должен описывать действие.
- `_buildFooter`: `DateTime.now().year` вызывается в `build`.
- `showLicensePage` открывает стоковый материаловский экран — вне темы, вне типографики, вне M3E. Либо тематизировать, либо свой `/legal/licenses`.
- `Divider(color: outlineVariant α0.15)` — при альфе 0.15 разделитель практически невидим, и он идёт во всю ширину вместо отступа под лид-иконку (в `settings_ui` для этого уже есть `Divider(indent: 58)`).
- Пункт списка изменений рисуется точкой-контейнером, а в раскрытой версии — символом `'• '` в `Text`. Два разных маркера для одного смысла.
- `_openUrl` → `AppUrlLauncher.openUrl`: проверить режим запуска. Если это `LaunchMode.externalApplication`, то Telegram/[ni-os.ru](http://ni-os.ru) выкидывают из приложения так же, как ссылка Nios ID в Настройках. Нужен `inAppBrowserView` (Custom Tabs).
- `parseAllReleases` гоняется по всему файлу на UI-потоке при каждом открытии экрана (кэш в `State`, а не в провайдере).
- Радиусы на одном экране: 28 (hero) / 20 (карточки) / 16 (табы, аватар) / 14 (OTA-иконка, кнопка) / 12 (чипы, поля) / 10 (иконка строки) / 6 (чип роли). Должны быть только токены `AppRadii`: `sm 12`, `md 20`, `lg 28`, `full`.
- Размеры иконок: 12 / 13 / 14 / 15 / 18 / 20 / 22 / 26. Оставить 18 / 20 / 24.
- `fontSize` руками задан в 14 местах поверх текстовой темы. По аудиту дизайн-системы шкала и так сжата — локальные оверрайды делают её неуправляемой.

## 8. Критерии приёмки

1. Десять тапов по лого подряд: ни одного кадра дольше 8 мс на tier A, в timeline нет `saveLayer` от бренд-марки, фигуры перетекают без второй копии в кадре.
2. Во время морфа на экране ровно одна фигура; быстрые тапы не накладываются.
3. Количество виджетов в табе «Новое» не зависит от длины `CHANGELOG.md` — проверяется тестом с файлом на 200 релизов.
4. Переключение таба перестраивает только входящий таб (проверяется счётчиком `build` у уходящего).
5. Лейблы сегментов не обрезаются при ширине 320 dp и `AppFontScale 1.3`.
6. Все интерактивные элементы ≥ 48 dp по обеим осям, включая версионный бейдж и ссылки.
7. Аватары команды читаются в светлой и тёмной теме и в OLED-режиме (контраст к фону ≥ 3:1).
8. Роль разработчика видна целиком, без многоточия, на ширине 320 dp.
9. На экране не более четырёх радиусов и не более трёх размеров иконок.
10. `flutter analyze` — ноль, `dart test` — зелёный, включая новый тест на морф-painter (проверка, что путь замкнут и радиусы монотонно интерполируются).
